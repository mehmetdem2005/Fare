# S9.5 — collision-first priority and stale queue discard
Original chunk scanning was coordinate order (-2 z first), delaying current and adjacent colliders after sudden direction changes or teleports. This patch always removes stale queued requests before sorting; sorts missing chunks by Chebyshev safety ring (current 0, adjacent 1, outer 2), then predicted position from current velocity 2 seconds ahead, then stable world coordinates. The inner 3x3 physics safety ring remains top priority and never yields to camera direction. Original world noise, render assets, flow, seed and 49-bone mouse rig unchanged. CI teleports from positive to negative z and asserts exactly 25 valid requests, current chunk first, increasing safety ring, no stale coordinates.
This is a limited O(25log25) priority queue, not a full large-world heap/scheduler. It cannot make main-thread physics shape creation free; Android sustained FPS and collision misses must still be measured on device.
