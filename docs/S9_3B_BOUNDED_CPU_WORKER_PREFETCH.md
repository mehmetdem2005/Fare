# S9.3b — Pure CPU worker prefetch, bounded, collision-safe fallback (experimental)

Godot 4.7.2 Android S9.2b, original 49-bone GLB and deterministic RiverProfile/flow preserved.
S9.3a test generated 3 chunk coordinates in WorkerThreadPool using 100% private FastNoiseLite, RiverProfile, ShoreSubstrate, RiverFlowField instances; compared post-ArrayMesh terrain and water buffers exactly with original and flow RGBA8 bytes. ImageTexture, ArrayMesh, physics shapes and SceneTree are **never** created or edited on workers. Two parallel workers maximum.

For active Android world, predict +3 chunks in the player velocity direction, avoiding precompiled and user-cached tiles. A miss when requested in outer ring queues a worker task instead of blocking the frame for 0.5–1.0s; once CPU ready, the main thread creates terrain/water ArrayMesh and flow Image/texture, cooks collision, adds major boulders, then separately schedules decorative details. For current/adjacent chunk, synchronous generation remains a physical collision safety fallback (teleports/very late jobs). RAM only keeps six CPU-ready packages, and every worker task is completed/joined before its data is read or discarded; stale far results are ignored. No endless async task leak; closing the scene joins remaining jobs. Existing direct _add_chunk() call in tests uses original behavior for headless Linux.

Metrics in phone JSON include inflight, ready, started/finished, used, discarded, collision_fallback and deferred request count. Worker **CPU runtime is not gameplay frame time**; interpret separately. This reduces main-thread generation stalls when prefetch completes *early*, but not necessarily render GPU-bound fixed-scene p95 or CPU contention/thermal under concurrent work; only device A/B decides. No cache schema/atomic write changes in this patch.

Safety tests: exact geometry and flow equivalence, stale result cancellation, collision always present in current 3x3, 49-bone rig, bounded memory and Android S9 build tags. Feature flag s9_worker_enabled defaults true only in Android path (Linux tests manually exercise worker). Set false for rollback; never merge PR #2 until on-device comparisons verify seams, water direction and no falling.
